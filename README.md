# SAY MY NAME

Frontend-only hackathon prototype for PS 10: Fake News & Sentiment Detectivity.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal. Use **Use demo account** on the login screen.

## Included

- Responsive React + Vite interface with Tailwind CSS dependency and Lucide icons
- Local demo authentication using browser `localStorage`
- Deterministic local analysis for text, image metadata, URL signals, combined context, and voice transcript
- Browser FileReader image previews and Web Speech API voice input with demo fallback
- Explainable credibility, sentiment, confidence, risk, signals, and AI insight cards
- Persistent analysis history and overview statistics
- No backend, database, authentication server, or external API

Default credentials: `9876543210` / `saymyname` / `SayMyName@123`

This is a hackathon/demo authentication system and is not production security.
